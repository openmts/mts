# Dashboard UX P261–P262（2026-07-21）

## 目标

- P261：Overview 自动刷新 soft-fail，对齐 Metrics（保留快照 + PartialErrorBanner + 首轮 toast）
- P262：Overview 自动刷新/手动刷新 a11y（`aria-pressed` / `aria-busy` / testid）

## 非目标

- refresh token、边缘证书/HSTS 实装、跨主机备份告警
- 全站排序按钮 `aria-sort` 大扫（后续可选）

## 实现

### P261

- `loadOverview({ background?: boolean })`
  - hard：`loading` + 清空 `loadError`/`adminSectionErrors`
  - soft：不抬 loading；`/healthz` 失败且已有快照 → `refreshError` + 首轮 toast；成功则清 refresh 错误
  - admin 分项：`loadAdminBundle(softKeep)`；soft 失败保留分项数据，仅记 `adminSectionErrors`
- 自动刷新：`setInterval(() => loadOverview({ background: true }), 10000)`
- i18n：`overviewRefreshFailed`（zh/en）
- e2e：健康路径 `overview-refresh-error` count 0；`overview-auto-refresh` / `overview-refresh` 可见

### P262

- `overview-auto-refresh`：`aria-pressed`
- `overview-refresh`：`aria-busy` + spin 图标
