# Dashboard UX P187–P188（2026-07-21）

## P187 — 登录 / 强制改密 redirect 透传与展示
- [x] EARS-FE-P187-01 WHEN 登录页带有合法 `redirect` query THE SYSTEM SHALL 展示「登录后将返回」路径（截断展示，不含 token）
- [x] EARS-FE-P187-02 WHEN 未登录访问受保护路由 THE SYSTEM SHALL 跳转登录并携带 `redirect=原路径`
- [x] EARS-FE-P187-03 WHEN 登录成功且无需改密 THE SYSTEM SHALL 回到 sanitize 后的 redirect（优先于落地偏好）
- [x] EARS-FE-P187-04 WHEN 登录成功但需强制改密 THE SYSTEM SHALL 将 redirect 透传到 ForceChangePassword
- [x] EARS-FE-P187-05 WHEN 强制改密成功 THE SYSTEM SHALL 回登录页并保留 redirect + reason=password_changed
- [x] EARS-FE-P187-06 WHEN 未登录进入 ForceChangePassword THE SYSTEM SHALL 回登录并保留 redirect
- [x] EARS-SEC-P187-07 sanitizeRedirect 拒绝 `//`、外链、`/login`、`/force-change*`
- [x] EARS-TEST-P187-08 formatRedirectLabel / withRedirectQuery 单测
- [x] EARS-E2E-P187-09 商业冒烟：登录 redirect 横幅 + 登出后深链回跳
