# MTS 用户管理模块二次闭环检视报告

## 结论

当前用户管理模块在本轮复核后，已经满足当前单机版本的完整性要求：接口化边界、默认本地实现、用户 CRUD、DB 级权限管理、持久化、第三方注入、公开 workflow 和质量门禁均已闭环。

本轮没有发现需要新增生产能力的缺口；发现的是测试证明不足的弱覆盖点，已全部补充自动化测试并通过验证。

## 本轮复核口径

- 范围：`github.com/openmts/mts` 根包 public 用户管理 API、`LocalUserManager` 默认实现、Engine 集成和 public e2e。
- 权限粒度：database 级别，权限为 `read`、`write`、`admin`，`admin` 隐含 read/write/admin。
- 非目标：密码登录、token 签发、session、HTTP 认证中间件和第三方权限系统实现。这些不属于当前用户模块规格；当前只提供身份与授权数据管理，以及第三方 `UserManager` 注入边界。

## 待实现项与闭环状态

### P1: 删除用户后授权清理缺少显式测试证明

状态：已闭环。

处理：新增 `TestLocalUserManagerDeleteUserRemovesDatabasePermissions`，覆盖删除用户后权限校验 fail closed、权限列表返回用户不存在、同名用户重新创建后不会继承历史授权。

### P1: 缺失用户权限校验 fail closed 缺少显式测试证明

状态：已闭环。

处理：新增 `TestLocalUserManagerCheckPermissionFailsClosedForMissingUser`，确认不存在用户执行权限校验时返回 `ErrPermissionDenied`，避免泄漏用户存在性。

### P1: 本地用户文件权限缺少显式测试证明

状态：已闭环。

处理：新增 `TestLocalUserManagerPersistsUsersFileWithPrivatePermissions`，确认用户目录权限为 `0700`，`users.bin` 文件权限为 `0600`。

### P2: ListUsers clone 行为缺少显式测试证明

状态：已闭环。

处理：新增 `TestLocalUserManagerListUsersReturnsClones`，确认调用方修改列表返回值不会污染内部用户 metadata。

### P2: 用户管理方法 canceled context 行为缺少完整测试证明

状态：已闭环。

处理：新增 `TestLocalUserManagerCanceledContextDoesNotMutateState`，覆盖 Create、Update、Get、List、Grant、Revoke、ListDatabasePermissions、Check、Delete 在 context canceled 时返回 `context.Canceled`，并确认状态未被修改。

### P2: 权限错误路径覆盖不完整

状态：已闭环。

处理：扩展 `TestLocalUserManagerRejectsInvalidPermissions`，补充撤销缺失用户、列出缺失用户权限、空 database 校验等错误路径。
