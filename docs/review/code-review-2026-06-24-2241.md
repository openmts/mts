# MTS Go 工具链漏洞修复检视报告

## 结论

本轮将项目 Go 版本从 `1.26.2` 升级到 `1.26.4`，用于修复 `govulncheck` 报告的 3 个可达标准库漏洞：`GO-2026-5039`、`GO-2026-5037`、`GO-2026-4971`。

由于本机全局 `GOSUMDB=off` 会阻止 Go 自动工具链下载校验，本轮同时让 `Makefile` 和 `scripts/ci_gate.sh` 对 Go 命令显式启用 `GOSUMDB=sum.golang.org`，保证 `go1.26.4` 工具链能被校验后下载和执行。

## 变更范围

- `go.mod`：声明 `go 1.26.4`。
- `Makefile`：新增 `GO ?= env GOSUMDB=sum.golang.org go`，并让测试、覆盖率、scale、pprof、bench 目标使用该命令。
- `scripts/ci_gate.sh`：新增 `go_cmd`，CI gate 内所有 Go 测试和覆盖率工具使用显式 checksum DB。
- `CONTRIBUTING.md`：环境要求升级到 Go 1.26.4，并说明 `GOSUMDB` 要求。

## 风险评估

- 本次没有新增第三方依赖。
- `1.26.4` 是当前可用的最新稳定版本；`1.27rc1` 是候选版本，不适合作为商用默认工具链。
- 显式启用官方 checksum DB 能恢复 Go toolchain 模块校验，避免在 `GOSUMDB=off` 环境下静默下载未校验工具链。

## 验证记录

已确认：

- `go list -m -versions go` 显示当前最新稳定版本为 `1.26.4`，同时存在 `1.27rc1`。
- `GOSUMDB=sum.golang.org go version` 可下载并运行 `go1.26.4 linux/amd64`。

已通过：

- `timeout 300s env GOSUMDB=sum.golang.org go mod tidy`
- `timeout 300s env GOSUMDB=sum.golang.org go mod verify`：`all modules verified`
- `timeout 300s env GOSUMDB=sum.golang.org go version`：`go version go1.26.4 linux/amd64`
- `timeout 900s make ci`
  - format：`goimports-reviser` 通过。
  - tests：`go test ./...` 通过。
  - lint：`golangci-lint` 0 issues。
  - coverage：根包 `91.8%`，`cmd/mts-storage` `92.0%`，生产包均达到 `>=90%`。
  - regression smoke 和 artifact scan 通过。
- `timeout 600s env GOSUMDB=sum.golang.org go run golang.org/x/vuln/cmd/govulncheck@latest ./...`：`No vulnerabilities found.`
- `timeout 60s git diff --check`
- 临时产物扫描：未发现 `.test`、`coverage.out`、`.prof`、`.pprof`、`.coverprofile` 残留。

## 最终判定

Go 标准库可达漏洞告警已消除。当前仍保留的发布治理建议是补远端 CI 和首个 release tag/API 兼容基线；它们不再是本轮 `govulncheck` 告警修复的阻塞项。
