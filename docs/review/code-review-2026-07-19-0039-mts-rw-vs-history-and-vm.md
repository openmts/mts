### 口径

- MTS 写：进程内 WriteTypedBatch；VM 写：HTTP Influx line（含协议成本）。
- MTS 查：本地整行 2000；VM 查：export 单字段/多字段。
- 1 逻辑点 = 10 字段；VM 侧对应 10 个 metric samples。

### 结论

1. 写入：MTS 更快（约 1.44x），含本地 API vs HTTP 红利。
2. 查询：VM 显著更快（单字段热查 0.83ms vs MTS 整行热查 68.26ms）。
3. 体积：同量级（MTS 6.50 vs VM 5.43 MiB，1.20x）；优化前约 114x 已拉齐。
4. 取舍：MTS 用写吞吐/磁盘换更重解码查询；VM 热读/扫描仍强。
