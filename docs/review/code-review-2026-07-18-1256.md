# 代码检视报告：Wide 布局 Write vs WriteTypedBatch 与列式批量写 API

- 日期：2026-07-18 12:56 +0800
- 范围：公开写路径 API、bench 对比、`PointsToTypedBatch` / `WritePointsAsTypedBatch`

## 对比结论（同一 wide 字段布局，points=10000, count=8）

| 路径 | ns/op median | B/op median | allocs/op median |
|---|---:|---:|---:|
| Write (WideBatch) | ~41.9ms | ~48.3MB | ~136342 |
| WriteTypedBatch (TypedWideBatch) | ~14.6ms | ~6.53MB | ~16247 |

- 时延：Typed 约为 Write 的 **35%**（约 **2.9x** 更快）
- 分配次数：下降约 **88%**
- 分配字节：下降约 **86%**

判定：收益显著，落地列式转换与批量写封装。

## 实现项

1. `PointsToTypedBatch([]Point) (TypedBatch, error)`：同构 batch 转列式
2. `Engine.WritePointsAsTypedBatch`：转换后走 `WriteTypedBatch`
3. bench：`makeWideBenchTypedBatch` + `BenchmarkEngineWriteTypedWideBatch`
4. 文档：README 批量写入补充转换示例

## 约束（转换）

- Database/RP/Measurement/Precision 整批一致
- field 集合完全一致，类型不可冲突
- 不支持稀疏 field
- tag key 取并集，缺失填空串
- 返回新分配，不借用输入 map
